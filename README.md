# IFPE_Projeto_TESE

Controle Distribuído de Atuadores com Arduino e Comunicação I2C

Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de implementar um sistema de controle 
distribuído utilizando dois microcontroladores Arduino UNO comunicando-se por meio do 
protocolo I2C. A solução permite o controle independente de três tipos de atuadores: 
motor DC, servo motor e motor de passo unipolar, utilizando um teclado matricial, um 
push button e um display LCD AIP31068 com interface I2C.

O sistema foi projetado para ser executado e validado em ambiente de simulação 
utilizando o SimulIDE, com desenvolvimento dos códigos realizado na IDE Arduino.

Objetivo

Desenvolver um sistema embarcado capaz de:

Implementar comunicação entre dois Arduinos utilizando o protocolo I2C;
Separar as funções de controle e acionamento dos dispositivos;
Permitir a seleção e o controle de diferentes motores por meio de um teclado matricial;
Exibir informações de operação em um display LCD com comunicação I2C;
Aplicar conceitos de eletrônica digital, sistemas embarcados e automação.
